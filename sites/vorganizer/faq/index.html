Getting started

What is vOrganizer?

vOrganizer sorts a messy folder by file type. Point it at Downloads, Desktop, Documents or any folder, and it moves images, documents, videos, audio, archives, code, installers and fonts into their own folders.

Which versions of Windows does it support?

Windows 10 (version 1809 or later) and Windows 11.

Where do I get it?

From the Microsoft Store. Updates arrive automatically through the Store.

Does it need an internet connection or an account?

No. vOrganizer works offline and needs no account.

How sorting works

Which categories are there?

Eight: Images, Documents, Videos, Audio, Archives, Code, Executables and Fonts, recognised by dozens of file extensions. Files that fit none of them go to an Others folder.

Where do my files end up?

In a folder named vOrganizer inside the folder you sorted, with one subfolder per category, such as vOrganizer\Images.

Does it touch files in subfolders?

No. Only the files that sit directly in the folder you chose are sorted.

Can I sort only some file types?

Yes. Turn categories on or off before you press Organize Now, and only the kinds you leave on are moved.

Can I see what will happen first?

Yes. Preview lists which files will go to which folder before anything moves.

Safety

Does vOrganizer delete anything?

No. It only moves files into category folders.

Can I undo a run?

Yes. Undo puts the files from the last run back where they were.

Is my data uploaded anywhere?

No. Everything happens on your PC. See the privacy page.

Support

How do I get help or report a problem?

Write to admin@kingpindev.com with your Windows version, your vOrganizer version and what you were doing.

How much does it cost?

The Store page always shows the current price.
