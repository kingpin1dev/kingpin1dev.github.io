Questions

Does vOrganizer delete anything?

No. It only moves files into category folders, and Undo moves them back.

Where do my files end up?

In a folder named vOrganizer inside the folder you sorted, with one subfolder per category, such as vOrganizer\Images.

Does it touch files in subfolders?

No, only the files that sit directly in the folder you chose.

Can I sort only some file types?

Yes. Untick the categories you want to leave alone before you press Organize Now.
