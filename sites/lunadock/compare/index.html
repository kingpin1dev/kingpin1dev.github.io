The Windows desktop on its own

Built in to Windows

Where it shines

Nothing to install. You can sort and align the icons on the desktop and keep your files wherever you like.

Where LunaDock differs

LunaDock gathers the desktop into stacks by type or date, new files find their stack by themselves, the stacks tuck away on a screen edge, and your files never move.

Pick it if

Stay with plain Windows if you keep only a handful of icons on the desktop.

Stardock Fences

Paid desktop utility from Stardock

Where it shines

Shaded containers (fences) that you place and size on the desktop, with rules that sort icons into them, tabs, roll-up fences and icon tinting.

Where LunaDock differs

LunaDock does not draw containers on your wallpaper. It folds everything into compact stacks on one screen edge that fan open on a click, picks the stack for each file automatically, and leaves the files where they are.

Pick it if

Pick Fences if you want free-form containers laid out across the desktop, rules you write yourself or business deployment tools.

Desktop Frames+

Free, open-source utility (MIT license)

Where it shines

Frames you place on the desktop, with tabs, roll-up frames and a tint setting, plus rules you write that move incoming files into frames or folders.

Where LunaDock differs

LunaDock does not draw frames on your wallpaper. It keeps compact stacks on one screen edge, picks the stack for each file by type or date on its own, and leaves your files where they are.

Pick it if

Pick Desktop Frames+ if you want a free, open-source tool with tabs and your own sorting rules.

iTop Easy Desktop

Free, with a paid Pro tier from iTop

Where it shines

One click sorts the desktop icons into boxes such as Documents, Images, Applications and Folders. It adds a search bar, a red spot on new files that have no box yet, and a switch to Apple or Samsung style icons.

Where LunaDock differs

LunaDock also files new files into their stack by itself, groups by date as well as type, docks on any screen edge and never moves a file.

Pick it if

Pick iTop Easy Desktop if you want one-click boxes with a built-in search and a free tier to start with.

LauncherX

Open-source Windows launcher (MIT license)

Where it shines

A central launcher for your chosen files, folders and websites, with groups, search, drag-and-drop and wallpaper-aware styling.

Where LunaDock differs

LunaDock organizes the files already on your desktop into stacks by type, date or application category, including new arrivals. The stacks open directly on the desktop.

Pick it if

Pick LauncherX if you want a searchable launch point for your favourite items.

Portals

Folder-based desktop organizer

Where it shines

Desktop panels show selected folders, with multiple tabs, sorting, minimized panels and layouts that can follow display changes.

Where LunaDock differs

LunaDock focuses on compact desktop stacks, automatic grouping and scrolling through a Deck of files, with extension and keyword rules for custom stacks.

Pick it if

Pick Portals if you want customizable folder panels and saved layouts for different display setups.
