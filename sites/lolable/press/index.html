One line / Short description / Full description

One line

Lolable is a Discord bot that shows League of Legends rank, form, live games and a server leaderboard with slash commands.

Short description

Lolable brings your server's League of Legends stats into Discord: link a Riot ID and get rank and LP cards, form and KDA, champion mastery, a last-match breakdown, live game scouting, comparisons and a server leaderboard. It uses Riot's public API and is not endorsed by Riot Games.

Full description

Lolable is a Discord bot for League of Legends communities. Players link a Riot ID with /bagla and then use /profil for a paged card with league, form, performance and champion pool, /sonmac for a breakdown of the last game, /live to scout a running game with both teams, ranks and recent form, /compare to put two players side by side and /leaderboard to rank the server by SoloQ LP. /feed posts match results, rank changes and streaks to a channel, /duo finds players in a similar league and a persistent /panel keeps working after restarts. Every statistic shows the sample size behind it. Data comes from Riot Games' public API and Data Dragon, players can delete their data with /baglantikes and /verisil, and Lolable replies in Turkish. It is not endorsed or supported by Riot Games.
