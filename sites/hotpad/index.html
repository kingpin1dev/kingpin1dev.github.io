FAQ

Questions

Why does it need a driver?

Windows sees all keyboards as one. The open-source Interception driver lets Hotpad tell your second keyboard apart. Setup installs it only if you tick the box.

Will my main keyboard be affected?

No. Only the keyboard you pick is captured. If Hotpad closes, keyboards go back to normal on their own.

Can I use it in online games?

Yes, but the responsibility is yours. Check the rules of every game you play before using a macro tool: some games and their anti-cheat systems restrict input drivers or automation. League of Legends now blocks macro programs at the kernel level, so Hotpad does not work in that game.

Where are my settings?

In %LOCALAPPDATA%\Hotpad\macros.json. Updates and uninstalling keep it.
