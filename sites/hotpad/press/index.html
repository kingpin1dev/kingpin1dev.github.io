One line

Hotpad turns a second keyboard into a dedicated macro keyboard for Windows.

Short description

Hotpad turns a spare keyboard into a macro keyboard. Its keys never reach Windows, so they can open programs, type text, send shortcuts, run step sequences and mute your microphone, while your main keyboard works as usual. Profiles, a live visual editor and a tray icon keep it out of the way. Free for personal use.

Full description

Hotpad is a Windows app for anyone with a small keypad or a spare keyboard lying around. Using the open-source Interception driver, it tells your keyboards apart and captures only the one you choose, so every key on it becomes a button for something you do often: opening a program or link, typing an address or a reply, sending a shortcut, running a short sequence of steps with delays, or toggling the Windows microphone while a game is full screen. A visual editor shows the key layout, lets you capture a key by pressing it and keeps working live while you edit. Profiles hold separate sets of keys for different games or jobs and can be switched from the app, the tray or a key. If Hotpad ever closes, the driver hands the keyboards back to normal. The per-user installer includes the .NET runtime, and the interface is available in English and Turkish.
