Getting started

What is Hotpad?

Hotpad turns a second keyboard (a small gaming keypad, a half keyboard or any spare keyboard) into a dedicated macro keyboard. Its keys never reach Windows; they only run the macros you set. Your main keyboard keeps working normally.

What do I need?

Windows 10 or 11 (64-bit), a second keyboard and the optional Interception driver, which is what lets Hotpad tell the two keyboards apart. The installer includes the .NET runtime and installs Microsoft's WebView2 if it is missing.

Is it free?

Hotpad is free for personal use. Commercial use needs written permission, see the licence in the installer.

Where do I get it?

From the download button on this site (kingpindev.com/hotpad). It is not on the Microsoft Store.

The driver

Why does it need a driver?

Windows treats every keyboard as one input device. To react to only one of them, Hotpad uses the open-source Interception driver, which lets it see which keyboard a key came from before Windows does.

Does the installer install the driver?

Only if you tick the optional box, and only if it is not installed yet. It needs administrator approval and a restart. If the driver is already there, setup leaves it alone.

What happens if Hotpad crashes or is closed?

The driver stops sending keys to Hotpad and your keyboards go back to normal on their own, so you cannot get locked out.

Can I use it in online games?

Be careful. Anti-cheat systems such as Vanguard, Easy Anti-Cheat or BattlEye can block or flag input drivers, and one key running several actions can count as automation in some games. Single-player games and everyday apps are fine.

Using Hotpad

How do I pick my second keyboard?

Press Select keyboard and tap any key on the small keyboard within 15 seconds. Hotpad remembers its hardware ID. If two keyboards share the same ID, Hotpad asks you to choose again instead of guessing.

What can a key do?

Open a program, file or link; type a ready-made text; send a shortcut such as Ctrl+Shift+Esc; run a sequence of steps with delays; or mute and unmute your Windows microphone.

Can I have different setups for different games or jobs?

Yes. Profiles hold separate sets of keys. Switch from the app, from the tray menu or with a key you choose. Drag profiles to reorder them.

Do changes apply while the editor is open?

Yes. Macros keep working while you edit and every change is applied live.

Does it start with Windows?

If you turn on Start with Windows, it runs quietly in the system tray when you sign in.

Your data

Where are my settings?

In %LOCALAPPDATA%\Hotpad\macros.json. Updating or uninstalling Hotpad keeps that file. You can also export all profiles from Settings.

Does Hotpad collect my data?

No accounts, analytics or advertising. Hotpad does not send anything over the internet. See the privacy page.

How do I get help or report a problem?

Write to admin@kingpindev.com with your Windows version, your Hotpad version and what you were doing.
