One line

Goliath is a Discord bot for moderation, levels, music and live radio, controlled entirely with slash commands.

Short description

Goliath keeps a Discord server in order: moderation with logs, a level system, music with a queue, live radio, a browsable help panel and everyday tools like translate, reminders and server info. Everything is a slash command, and it is free.

Full description

Goliath is a full-featured Discord bot with more than fifty slash commands. Moderation covers kick, ban, timeout, warnings, message clearing, slow mode and channel locking, with logs you route to a channel: deleted and edited messages, members joining and leaving, role and channel changes and voice activity. Members earn XP by chatting, with /rank and /leaderboard. Music plays from YouTube or Spotify links and searches with a queue, seek, shuffle, loop and volume, and a live radio panel tunes into stations in a voice channel. A help dropdown walks through every category, and handy tools add translation, weather, Wikipedia search, link shortening, reminders and AFK status. Goliath replies in Turkish and is free.
