Getting started

What is Goliath?

Goliath is a Discord bot that brings moderation, a level system, music and live radio, a browsable help panel and a set of everyday tools to your server. Everything is a slash command.

How do I add it to my server?

Use the Add to Discord button. You need the Manage Server permission on the server. Discord shows the permissions the bot asks for before you confirm.

Is Goliath free?

Yes.

Which language does it use?

Goliath replies in Turkish.

Do I need to learn commands?

No. Type / in any channel and Discord lists them with descriptions, or open /help for a dropdown that walks through every category.

Moderation and server tools

What can it moderate?

Kick, ban and unban, timeout, warn (with a list and clear), clear messages, slow mode, lock and unlock a channel, and recreate a channel.

Can it manage roles?

Yes. Give and take roles and look up role details.

Does it log what happens?

Yes. You can set where logs go: deleted and edited messages, members joining and leaving, role and channel changes, moderation actions and voice activity.

What server information can I look up?

Member count, server icon and banner, emojis, invites, bot info and detailed member statistics.

Levels

How do levels work?

Members earn XP by chatting. /rank shows level and progress, /leaderboard ranks the server, and admins can set a level. Level-up notifications are posted automatically.

Music and radio

How does music work?

Use /play with a YouTube or Spotify link or a search in a voice channel. There is a queue, pause, resume, skip, seek, jump, shuffle, remove, loop and volume, and YouTube playlists of up to 50 songs.

Does it leave the voice channel by itself?

By default after 5 minutes of inactivity. Stay mode keeps it in the channel, and admins can change the timeout.

What about live radio?

Open the radio panel to tune into live stations in a voice channel.

Everyday tools

What are the handy tools?

Translate, calculate, weather, search Wikipedia, shorten links, set reminders and go AFK.

Privacy and support

What data does Goliath store?

Only what its features need, such as level and XP counts, warnings, reminders, AFK status and server settings. See the privacy page.

How do I get help or report a problem?

Write to admin@kingpindev.com with your server name, the command you used and what happened.

Still have a question? Write to us at admin@kingpindev.com
