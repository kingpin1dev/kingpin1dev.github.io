Multi-purpose Discord bot

One bot to keep your server in order.

Goliath brings moderation, a level system, music and live radio, a browsable help panel and a set of everyday tools to your Discord server. Everything is a slash command, so there is nothing to memorise: type / and pick.

Try it here

A live Discord channel with Goliath in it. Click a command or type / and run it: /help, /rank, /leaderboard, /play, /queue and /ban work. Members and songs are made up, and the bot replies in Turkish.

What Goliath does

Moderation

Kick, ban, timeout, warn, clear messages, slow mode, lock and unlock channels, with a log channel you choose.

Levels and XP

Members earn XP by chatting. /rank shows progress and /leaderboard ranks the server.

Music

Play from YouTube or Spotify with a queue, pause, skip, loop, shuffle, seek and volume.

Live radio

Open a radio panel to tune into live stations in a voice channel.

Help panel

/help is a dropdown that walks through every category and command.

Roles and logs

Give and take roles, look up role details and set where logs go.

Handy tools

Translate, calculate, search Wikipedia, shorten links, set reminders and go AFK.

Server info

User, server, avatar, invite and member statistics in one command each.
