Window manager for Windows

Grab any window from anywhere.

GlideSnap brings the window handling of Linux desktops to Windows. Hold Alt and drag a window by any part of it to move it, drag with the right button to resize from the nearest corner or edge, and drop it on an edge to snap it. No more aiming for the title bar.

Try it here

A small desktop running in your browser. Hold Alt, or tap the on-screen Alt key, then drag a window by its body. Right drag resizes, the wheel changes opacity, and dropping on an edge snaps it.

What GlideSnap does

Move from anywhere

Alt + left drag moves a window by any part of it, not just the title bar.

Resize from any corner

Alt + right drag resizes from the nearest corner or edge, so you always grab the right one.

Snap and grid

Drop a window on an edge to maximize or tile it. Turn on 2x1, 3x1, 2x2 or 3x2 grids when you want them.

Opacity

Alt + wheel makes a window see-through, handy for keeping an eye on what is behind it.

Always on top

Alt + middle click pins a window above the rest and unpins it again.

Back to its size

Dragging a snapped window out gives it back its previous size.

Your own keys

Choose Alt, Ctrl or Shift and what each mouse button does.

Stays out of the way

Lives in the tray, can start with Windows and skips apps you exclude by title, class or .exe.

Questions

Does it work on every window?

On almost all of them. Windows does not let a normal app control elevated or protected windows.

Can I change the Alt key?

Yes. Pick Alt, Ctrl or Shift and set what each mouse button does.

Can I exclude an app?

Yes. Exclude by window title, window class or .exe name, or pause GlideSnap from the tray.

Does it run at startup?

Only if you turn that option on.
